# ☕ Coffee Shop Landing Page

Landing page moderna de uma cafeteria, desenvolvida com HTML e CSS, com foco em design responsivo, organização visual e boa experiência do usuário.

## 🔹 Funcionalidades

- Layout responsivo e moderno  
- Menu de produtos com preços e destaque visual  
- Seção de avaliações de clientes  
- Integração com Google Maps  
- Efeitos visuais com hover e transições

## 🔹 Tecnologias utilizadas

- HTML5  
- CSS3  
  - Flexbox  
  - Grid
